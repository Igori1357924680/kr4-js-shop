## Описание JavaScript-файлов
data.js — массив товаров (10 штук) с полями: id, title, category, price, isAvailable, description.

catalog.js — генерация карточек товаров, реализация поиска, фильтрации по категории и сортировки по цене/названию.

cart.js — логика корзины: добавление, удаление, расчет суммы через reduce, сохранение в localStorage, безопасный вывод уведомлений без alert().

validation.js — базовая валидация формы заявки.

main.js — точка входа, инициализация каталога и общих элементов (модалка, кнопка «Наверх»).

## Реализованные функции
Массив товаров: 10 объектов с уникальными id. Цены записаны числами.

Каталог: карточки генерируются через document.createElement, данные вставляются через textContent (безопасно). Используется classList и append.

Поиск: реагирует на ввод (addEventListener('input')), ищет по названию.

Фильтрация: работает по категориям через change.

Сортировка: по цене (возрастание/убывание) и по названию. Сортируется копия массива [...products].

Валидация формы: проверка имени, email и телефона. Ошибки выводятся на страницу (без alert()), поля подсвечиваются красным.

Безопасность: пользовательские данные не вставляются через innerHTML.

## Самостоятельные доработки
Корзина: добавление товаров, удаление, подсчет количества.

Расчет суммы: реализован через reduce.

Сохранение состояния: корзина сохраняется в localStorage и не пропадает при перезагрузке страницы.

Счетчик товаров: в шапке сайта отображается количество товаров в корзине на всех страницах.

Уведомления: всплывающие плашки при добавлении товара вместо стандартных alert().
