# PlayTable — адаптивный сайт (КР №3)

## Контрольная работа №3
Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

В проекте реализована адаптивная версия сайта интернет-магазина гаджетов PlayTable на основе проекта КР №1. Bootstrap не используется. Вся адаптивность выполнена с помощью CSS-медиазапросов, Flexbox и Grid.

## Адаптивные решения
Подход Mobile First: базовые стили написаны для мобильных устройств, расширение происходит через @media (min-width: ...).

Медиазапросы: настроены для ширин 768px, 1024px и 1440px.

Навигация: на мобильных меню перестраивается в столбик, на десктопе — в строку.

Сетка карточек: на мобильных 1 колонка, на планшетах 2, на десктопе 3-4 (CSS Grid).

Горизонтальный скролл: у body установлено overflow-x: hidden, чтобы избежать прокрутки всей страницы вбок.

Адаптивная таблица: таблица характеристик обернута в .table-wrapper с overflow-x: auto, чтобы прокручивалась только она, а не весь сайт.

Responsive Images: изображения сжимаются через max-width: 100%, а карточка товара использует srcset и sizes для загрузки подходящего размера.

## Доступность (A11y)
Добавлен Skip-link («Перейти к основному содержимому»), который появляется при нажатии клавиши Tab.

У всех полей формы есть label с корректным for.

У изображений осмысленный alt.

Навигация обернута в <nav> с aria-label.

Модальное окно реализовано через <dialog>, что обеспечивает базовую доступность с клавиатуры.

Проверен видимый фокус для всех интерактивных элементов.

Исправлен контраст текста и бейджей для соответствия стандартам.
